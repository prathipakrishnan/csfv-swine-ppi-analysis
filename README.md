# Computational Analysis of CSFV–Swine Protein–Protein Interactions

## Project Overview
This project investigates protein–protein interactions between Classical Swine Fever Virus (CSFV) and swine proteins using computational bioinformatics approaches.

## Methods and Tools
- Protein structure prediction and analysis
- AlphaFold-based computational analysis
- Protein–protein interaction investigation
- Python and Jupyter Notebook

## Project Notebooks
- `AlphaFold_protein_and_chemicals_ (1).ipynb`
- `Permutation_and_combination (1).ipynb`
- `final_output_of_swine_and_protein (1).ipynb`

## Publication
The research is published in *Virus Genes*.

DOI: [10.1007/s11262-026-02245-8](https://doi.org/10.1007/s11262-026-02245-8)
